Five ways to find a file by where it came from

People remember “Sam sent it on Slack” better than a folder. macOS saves where every download came from (the app, the website, the sender), and this screen groups files by it. Every option uses the same 913 downloads from 7 sources and the same Mail files. Real app icons replace the coloured letter tiles in the app.

My pick: 1, Sources and files. The sources stay in a list on the left with their counts, and the files from the chosen one sit on the right, each with its sender or website and when it arrived. One screen answers both “where did it come from?” and “which file?”, with no going back and forth. It works like Mail’s mailbox list, so it needs no learning. 2 (Source cards) is the more eye-catching choice for a first look.
