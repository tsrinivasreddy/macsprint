# MacSprint logo options

Candidates for the MacSprint logo. Nothing here is chosen yet; the current brand is still the
name-only "Mac S P R I N T" (see `../FOUNDATIONS.md`).

| File | What |
|---|---|
| `macsprint-logo-kit.svg` | Everything on one board: 16 marks, 8 name styles, 6 pairings in the app sidebar (light and dark). Drag it into Figma: shapes and text stay editable |
| `macsprint-logo-kit-preview.png` | A picture of the board |
| `marks/m01…m16-*.svg` | Each app-icon mark alone, 1024 × 1024 |

- Marks M1–M12 are also on the design canvas: https://claude.ai/artifact/GVSYuQgVEktZCvUL584gFw
- M13–M16 come from the app's own screens: the Library kind colours, the storage card, the Clean Up ring and the centred search field.
- Name styles use SF Pro (SF Pro Rounded for N4). In Figma, pick SF Pro if it is installed, otherwise Inter.
- Pick by number, e.g. "M1 + N2". The chosen pair then goes into `../FOUNDATIONS.md`, the website, the flows page and the favicon.
