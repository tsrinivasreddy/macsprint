## 2. Everyday tasks, and the fastest way to do each

| # | What people want to do | Where | Keyboard |
|---|---|---|---|
| 1 | Find a file they remember something about | Search | ⌘F, type, ↩ opens, Space previews |
| 2 | Get the file they just downloaded or saved | Recents | ⇧⌘R, it is first; drag it into Mail |
| 3 | Find a password or number seen in a screenshot | Search | ⌘F, type the words, ⇧⌘C copies the text |
| 4 | Find the file someone sent | Downloaded From | ⇧⌘J, pick the source |
| 5 | Look through photos in a folder | Image Viewer / Quick Look | Space, ← → |
| 6 | Get space back | Clean Up | ⇧⌘K, Review, ⌘⌫, ⌘Z to undo |
| 7 | Remove copies | Duplicates | ⇧⌘D |
| 8 | Paste something copied earlier | Clipboard | ⇧⌘V |
| 9 | Tidy and rename Downloads | Organizer | ⇧⌘O |
