Five ways to get back what you copied

Most of the time Clipboard is a panel: you are typing somewhere else, press ⇧⌘V, pick an older copy and it is pasted. Every option shows that panel over the same writing window, with the same items: two pinned, then today’s copies from Safari, Mail, Slack and a screenshot. Return pastes, ⌥ Return pastes as plain text, ⌘P pins. Password fields are never recorded.

My pick: 1, Search panel. A centred panel with a search field on top, Pinned first, then today’s copies with where each came from. Type to filter, arrows to move, Return to paste. It works like the search people already use on the Mac, so it is learned in a second, and the footer shows every key. 2 (List and preview) is better if people often copy long text or images and want to check before pasting.
