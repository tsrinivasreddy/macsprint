Rename the whole pile, or pick files

When a pile opens in Organizer, every unclear name gets a new name in blue. These options add a clear control for two choices: use the new names for the whole pile at once, or pick which files get them. The tick on the left still decides whether a file moves; renaming is a separate choice, labelled with words. Files with clear names are always left alone, and every rename can be undone.

My pick: 1, one segmented control: All · Choose · None. The whole choice fits in one control with three words. “All” renames the whole pile, which is what most people want. “Choose” shows a Rename tick on each file only when you ask for it, so the list stays simple until then. 5 shows the same control in Grid.
