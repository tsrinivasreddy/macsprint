Which style fits MacSprint

Chosen: Graphite. Quiet and closest to built-in macOS. It sits well next to any wallpaper and any accent colour, and it lets the yellow match boxes and red error marks in results stand out.

Runner-up: Ocean if search should feel more like a blue MacSprint place.

All five use the same search and results. The Mac appearance switch above changes these too.

Field styles

Sunset follows your reference. The others keep the same shape: a soft gradient behind, a frosted pill, a tinted icon and a microphone on the right. Each one has a light and a dark version. Tap one to use it above.

AI always on

What changes

  • The AI switch is removed from the field and from Settings.
  • Every search reads the text in images, the names and what a picture shows.
  • The reason line under each result (Text in image, Name, What it shows) stays, so people can see why a file matched.

When AI is not available

  • On Intel Macs, or when Apple Intelligence is off, search quietly uses names and image text only.
  • The result footer says “Smart search needs Apple Intelligence” once, with no switch to hunt for.
  • Everything runs on the Mac, so there is no privacy reason to need an off switch.

Is voice free on a Mac?

Yes. Every piece below is a built-in Apple framework that runs on the Mac. There is no cloud bill and no per-search cost. The only cost is the Apple Developer Program, which you need to sign and ship any Mac app, voice or not.

Watch for

  • Turn on on-device recognition. The older server mode sends audio to Apple and has daily limits.
  • Each language model downloads once the first time it is used. Show a small “Getting voice ready” state.
  • Add the microphone and speech recognition reasons to Info.plist, and the audio input entitlement for the App Sandbox.

Shipping

  • Building and testing on your own Mac costs nothing.
  • Shipping to other people needs the Apple Developer Program (US$99 a year) for signing and notarisation, or for the Mac App Store.
